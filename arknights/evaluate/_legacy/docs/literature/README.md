# 卫戍协议 agent：两轮引用雪球与选型

核查日期：2026-10-18。目标为固定开源规则中的终极模拟，并兼顾混合盟约和不同水平队友。**最直接的新增参考是 FCP、E3T 和 ZSC-Eval**：分别对应历史水平队友池、混入随机行为的队友训练、陌生队友评测。它们在其他合作游戏中的结论不能替代卫戍实测。

## 检索过程可以复查

本机 `openalex --help` 因安装缺少 `dist/index.js` 失败，改用同源的 `api.openalex.org`，没有要求用户提供 key。脚本为 `snowball.py`，请求和原始返回分别在 `openalex-queries.jsonl`、`raw/`。

1. 人工核对 8 条种子记录，覆盖 7 个论文家族：FCP、Other-Play、MEP、MAPPO、AlphaStar、合法动作掩码、Ludus。MAPPO 的会议和预印本记录分开保留，因为会议条目的参考文献字段为空；不能把它们算两个独立算法。
2. 第一轮从种子的参考文献和引用它们的作品扩展：新增 486 条，含种子共 **494 条 OpenAlex 记录、541 条有方向的引用边**。
3. 在第一轮新结果中，人工选择 8 个方向继续第二轮：不同奖励水平伙伴、TrajeDi、自动课程、COLE 扩展版、自走棋阵容分析、人类合作偏差、分层人口训练、分阶段多样性优化。具体 ID 和选择理由在 `selection-round-2.json`。
4. 第二轮再展开它们的前向/后向引用，新增 **191 条记录**；累计 **685 条记录、819 条引用边**。图中作品均未出现晚于本次核查日的出版日期。

这是真正沿引用关系做的两跳检索，不是把两组关键词搜索叫作两轮雪球。每个前沿节点的被引结果取高被引前 40 条及最新 15 条，去重后合并；参考文献按实际返回 ID 批量获取。**它是有边界的引用邻域，不是该领域全部论文**，也没有全文读完 685 篇。初始标题搜索曾误匹配 Ludus，已用 DOI `10.1609/aaai.v36i11.21550` 更正，原始失败匹配仍在台账。

OpenAlex 负责发现与关系追踪，方法判断尽量回到论文正式页面、原文和作者代码。记录可能把同文的会议/预印本分开，引用缺失也不表示论文没有参考文献；FCP 索引记录的参考文献为空，因此其后向覆盖受限。

## 优先级与本项目用法

| 参考 | 核实的要点 | 卫戍中的用途与限制 |
|---|---|---|
| [FCP，NeurIPS 2021](https://papers.nips.cc/paper/2021/file/797134c3e42371bb4979a462eb2f042a-Paper.pdf) | 从多个 self-play 策略抽取不同水平快照，冻结伙伴后再训练适应者；原文使用初始、最终及达到最终回报约一半时的快照 | 优先复用队友池结构。中等水平按能力而非训练时间一半选择；保留不同流派和随机种子。原实验是 Overcooked，不证明卫戍通关 |
| [E3T，NeurIPS 2023](https://papers.neurips.cc/paper_files/paper/2023/hash/07a363fd2263091c2063998e0034999c-Abstract-Conference.html) | 以自身策略和随机策略的混合构造伙伴，并从历史预测伙伴动作，减少预训练人口的负担 | 很贴合“混入蠢 AI”。作为 FCP 风格队友池的对照实验；随机分支只在卫戍合法动作中抽样，并限制不可挽回的失误。不是只加噪声就等于完整 E3T |
| [ZSC-Eval，NeurIPS 2024 D&B](https://proceedings.neurips.cc/paper_files/paper/2024/hash/54a7139c548c88e288aa0fcd2bcbeceb-Abstract-Datasets_and_Benchmarks_Track.html) | 用行为偏好生成评测伙伴，按 Best-Response Diversity 选择，使用 Best-Response Proximity 辅助度量 | 优先借用评测思想与池管理。按不同策略家族留出队友；近似最佳响应需要额外训练/搜索，不伪称已知最优上界；保留原始通关率 |
| [MEP，AAAI 2023 / arXiv](https://arxiv.org/abs/2112.11701) | 人口熵奖励促进多样性，再通过优先采样训练合作策略 | 当历史池实际出现同质化时再比较；多样性需同时覆盖打法与水平，层数数值不同不能直接充当策略差异 |
| [TrajeDi，ICML 2021](https://proceedings.mlr.press/v139/lupu21a.html) | 在轨迹分布上鼓励策略多样性，研究与未见伙伴的配合 | 为多样性指标提供候选。先用盟约、升级节奏、资源分配、兜底角色等可解释特征分析，之后再决定是否加训练损失 |
| [COLE / 合作不兼容，JAIR 扩展版](https://arxiv.org/abs/2306.03034) | 关注人口中仍无法配合的策略，以合作关系驱动开放式学习 | 记录跨配合矩阵和最差分组；不能仅因为平均自配合提升就晋升模型。不是套用零和对手 Elo |
| [MAPPO，NeurIPS 2022](https://arxiv.org/abs/2103.01955) | 给出 PPO 在合作任务中的强基线与实现消融 | 是多席位训练器的参考；集中 critic、分散 actor 不会自动消除陌生队友过拟合，仍要独立定义队友分布 |
| [合法动作掩码，FLAIRS 2022](https://arxiv.org/abs/2006.14171) | 说明 policy gradient 中掩码的依据和大非法动作空间的影响 | 实现购入/移动/装备等条件化掩码。现有基线 8 个非法样本均为移动 `BAD_TILE`，不能只检查资金是否足够 |
| [Other-Play，ICML 2020](https://proceedings.mlr.press/v119/hu20a.html) | 利用游戏对称性削弱 self-play 的专属惯例 | 可参考对称性检查和陌生搭档评测。卫戍的朝向、地形、路线、装备位置不必对称，不能直接随机置换棋盘坐标 |
| [Ludus，EAAI 2022](https://ojs.aaai.org/index.php/AAAI/article/view/21550) | 自动对战测试与全局搜索用于自走棋卡牌平衡 | 借鉴构筑候选采样和评测降本；不是已经训好的 TFT 强玩家，也不是我们的通关策略 |

Other-Play 的 [原始论文](https://arxiv.org/abs/2003.02979)与 [Carroll 等 2019](https://arxiv.org/abs/1910.05789)分别补充专属惯例、人类行为与 self-play 分布偏差的问题。后者也提示：弱脚本不能充分代表人，未来若有真实玩家轨迹，应另外验证。

两个邻近方向仅列为候选：`W4239679890` 的 Chess Rush 阵容挖掘工作使用阵容强度模型与遗传搜索；`W4402353287` 的 IJCNN 2024 工作描述以奖励条件化的策略生成高低水平伙伴。当前只核对到它们的索引摘要/标识，尚未读到完整原文或确认可运行官方代码，不把它们列为已验证实现。`W4401415886` 的 PDO 主要实验在对抗/机器人环境，与本任务距离更大，暂不采用。

## 对训练方案的具体调整

保留 **攻略 → 当前机制核验 → 自然 rollout → BC → 带掩码 PPO** 的主线。合作版本先比较三个相同模拟预算的设置：只与最新自身搭档、冻结的多水平/多流派队友池、带合法随机失误的混合队友。每组保持同样的基础训练器、观察和奖励，避免同时修改模型大小和训练量。

FCP 原文的冻结伙伴阶段值得优先复用：主模型必须适应对方，而不是等所有队友同时迁就它。以后周期性刷新池子时保留历史覆盖，单局内固定权重。中等水平、弱水平应由独立成绩和行为画像界定，不能只依据 checkpoint 文件名。

评测按队友家族、水平、地图/禁用和单人/多人分组，独立种子固定。报告终极通关率、最差分组、失败回合和跨配合下降；对完全不动等压力测试单列结果。用户提出的弱 AI 训练属于受控分布扩展，实际的“真实匹配分布”仍待真实玩家数据测量。
